Patch release: a false-positive fix for bare version flags.

* fix(version): defer when a version flag is the sole argument by @karlkfi in https://github.com/karlkfi/claude-prod-guard/pull/36

`ansible --version` denied as an ambient-target command, and so did `gcloud`/`aws`/`az`/`argocd` — every covered tool whose evaluator resolves an ambient target with no verb table to catch a bare `--version`. A segment whose *only* argument is a version flag (`--version`, `-version`, `-V`, `-v`) now defers.

The sole-argument constraint is load bearing: `--version` takes a value on mutating subcommands (`helm install … --version 2.0.0`, `eksctl create cluster --version 1.29`), so matching the flag anywhere in argv would open a prod bypass.
