# Extend entry-operand resolution to the PowerShell tool

`Remove-Item`/`Move-Item` have a read/write `role` but no entry role, so removing a symlink is still judged by its target, unlike Bash. Port `ENTRY_OPERANDS` over ([plan](../../plugins/workspace-guard/docs/plan/entry-operands.md)).
