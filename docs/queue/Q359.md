# A sleep in a substitution or sh -c body inside a loop is not a loop poll

foreground-guard defers on `while true; do gh pr checks 1; x=$(sleep 5); done`,
which polls forever. A `sleep` the loop body runs through `$( )`, `bash -c` or
`eval` never counts toward the loop finding, so only the bare-sleep floor
judges it, and a sleep under the floor (10 s by default) passes.

Measured 2026-11-16 driving
`plugins/foreground-guard/scripts/bash-foreground-guard.py` with a `Bash`
payload, on `origin/main` at `61695c2f` and again on the Q283 fix at
`5eecfc65` (same verdicts on both):

| command | foreground-guard |
|---|---|
| `while true; do x=$(sleep 1); done` | none |
| `while true; do bash -c 'sleep 1'; done` | none |
| `while true; do eval 'sleep 1'; done` | none |
| `while true; do gh pr checks 1; x=$(sleep 5); done` | none |
| `while true; do x=$(sleep 30); done` (control) | deny, bare-sleep floor |
| `while true; do (sleep 1); done` (control) | deny, loop |

Each nested body is analysed by a recursive call with its own state, at
`plugins/foreground-guard/scripts/bash-foreground-guard.py:807:        sub_f, sub_o = analyze_class_a(body, cfg, depth + 1)`,
and the caller merges only the findings and the override back. Whether the
body ran a foreground `sleep` never reaches the caller's loop check. That is
read from the code, not traced.

Found while working Q283, which ties a `sleep` to the loop around it. This
is the inverse case: a sleep that is inside the loop and not seen there.

## Which way it gets built

Have the recursive call also report whether its body ran a foreground
`sleep`, and count that toward the loop finding when the segment holding the
body is inside a loop. A body that is backgrounded, or under `timeout`, stays
exempt as it is today. Fixtures: each `none` row above should deny with the
loop reason, and both controls keep their verdicts.

## If it is never built

A poll loop that waits through a substitution or a `bash -c` holds the main
thread for as long as it runs, as long as each wait is under the floor.
