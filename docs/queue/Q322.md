# An escaped `$` or backtick in a double-quoted `bash -c` body is hidden

Inside double quotes bash removes the backslash from `\$` and `` \` ``, so
the body a `bash -c "…"` or `eval "…"` hands on holds a live `$X` or a live
backtick substitution. prod-guard reads the body with the backslash still in,
so neither is live there, and the command defers:

- ``bash -c "echo \`kubectl … delete …\`"`` runs kubectl in the child with an
  explicit production context and no variable involved.
- `bash -c "\$X kubectl …"` hands the child `$X kubectl …`, and with `X`
  unset the child runs kubectl: the shape Q298 fixed, one quoting level down.

Found by the prod-guard reviewer on the Q298 and Q290 pull requests (#288,
#290), and re-measured 2026-11-01 on the Q290 branch, fixture `$HOME` with
current context `gke_acme_prod-us`. `<prod delete>` is
`kubectl --context gke_acme_prod-us delete ns x` in the first block and
`kubectl --context=gke_acme_prod-us delete pod x` in the second:

| command | bash 5.3.15 | guard, `main` and branch |
|---|---|---|
| ``bash -c 'echo `<prod delete>`'`` (control) | runs it | deny |
| ``bash -c "echo \`<prod delete>\`"`` | runs it | **defer** |
| ``eval "echo \`<prod delete>\`"`` | runs it | **defer** |
| `bash -c '$X <prod delete>'` (control) | runs it | deny |
| `bash -c "\$X <prod delete>"` | runs it | **defer** |
| `eval "\$X <prod delete>"` | runs it | **defer** |

The bash column ran each with `/bin/echo RAN` in place of kubectl under
`env -i /opt/homebrew/bin/bash --norc --noprofile`, with the inner `bash` on
`/opt/homebrew/bin` and printing `5.3.15(1)-release`. Every row printed `RAN`.

## Where it happens

Python's `shlex` keeps the backslash in posix mode for both:
`shlex.split('bash -c "\\$X kubectl"')` returns `['bash', '-c', '\\$X kubectl']`,
and `shlex.split('bash -c "echo \\`k\\`"')` returns
`['bash', '-c', 'echo \\`k\\`']`. Bash removes the backslash before `$`,
`` ` ``, `"`, `\` and a newline inside double quotes. Not measured: whether the
shared `QuoteTrackingLexer` in `lib/bouncer_parse.py` is where to fix it, and
so whether the other four guards see the same body. Settle that before
labelling the row `lib`.

## If it is never built

A production mutation inside an escaped backtick substitution in a
double-quoted `bash -c` or `eval` body passes silently with its target written
out in full, and so does one behind an unset variable there. How often
sessions write either is not measured.
