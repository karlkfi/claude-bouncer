# A `)` glued to the next operator hides that command from branch-guard

branch-guard asks before `git commit` on `main`. When a `)` sits directly
against the operator after it, the hook returns no decision. That covers a
subshell's `)`, a `$(…)`'s and a `<(…)`'s alike. With a space before the
operator, the hook asks again. bash runs the commit either way.

branch-guard's `tokenize` emits the `)` and the operator as one punctuation
token, such as `);`, `)&&`, `)|` or `)&`. `command_segments` splits only on
whole operator tokens, so the `git commit` stays inside the previous segment
and is never classified. On `origin/main` at `ea64a90`:

```
tokenize('(true); git commit -m x')
  -> ['(', 'true', ');', 'git', 'commit', '-m', 'x']
command_segments(...)
  -> [(['true', ');', 'git', 'commit', '-m', 'x'], False)]
tokenize('(true) ; git commit -m x')
  -> ['(', 'true', ')', ';', 'git', 'commit', '-m', 'x']
command_segments(...)
  -> [(['true'], False), (['git', 'commit', '-m', 'x'], False)]
```

`split_operator_runs` in `lib/` already splits `);` into `)` and `;`, and
`)&&` into `)` and `&&`. branch-guard doesn't call it.

Found 2026-10-04 while driving the Q264 shapes through every hook. The
independent review of the Q264 pull request traced the mechanism and showed
that a plain subshell is enough. bash runs are under
`env -i /opt/homebrew/bin/bash --norc --noprofile -c`, which prints
`5.3.15(1)-release`. The hook ran on `origin/main` at `ea64a90` in a fresh
repository on branch `main`, with `P` set to `git commit -m x`:

| command | bash runs P | branch-guard |
|---|---|---|
| `echo a; P` -- control | yes | ask |
| `(true) ; P` -- space before the operator | yes | ask |
| `x=$(true) ; P` | yes | ask |
| `(true); P` | yes | **defer** |
| `(true)&& P` | yes | **defer** |
| `x=$(true); P` | yes | **defer** |

The review also measured `(true)| P` and `(true)& P` as defer.

## Which way it gets built

Run branch-guard's tokens through `split_operator_runs` before
`command_segments`, the way the other guards split a glued operator run.
Then check that `$(git rev-parse --show-toplevel)` and the other
pure-substitution idioms the module docstring lists stay auto-approvable.

## If it is never built

Any `)` written against the next operator removes branch-guard's prompt for
the command after it, and `x=$(…); git commit` is a shape agents write
routinely.
