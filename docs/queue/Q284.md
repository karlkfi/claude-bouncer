# prod-guard reads an unquoted heredoc body with its escapes still in

In an unquoted heredoc, bash removes the backslash from `` \` ``, `\$` and
`\\` before the command reads the body. prod-guard reads the body as written,
so `` \` `` stays an escaped character rather than the backtick the script
runs. A `#` between two of them then reads as a comment that takes the rest of
the line with it.

Driven 2026-10-05 under `env -i /opt/homebrew/bin/bash --norc --noprofile`
(5.3.15). The bash column ran the body from a script file with `echo RAN` as
P; the guard column used `kubectl delete ns payments` with the fixture context
set to `gke_acme_prod-us`, on `origin/main` at `26962b0` and on the Q254
branch:

| command | bash runs P | prod-guard, main / Q254 |
|---|---|---|
| `bash <<EOF` newline ``echo \`true\` ; P`` newline `EOF` | -- | deny / deny -- control |
| `bash <<EOF` newline ``echo \`true # c\` ; P`` newline `EOF` | yes | **defer** / **defer** |

The body reaches `_strip_comments(body, quotes=False)` unchanged. The shared
`strip_comments` reads `` \` `` as an escape pair, so after Q254 it still
finds no backtick span there:

```
strip_comments('echo \\`true # c\\` ; P')  -> 'echo \\`true '
strip_comments('echo `true # c` ; P')      -> 'echo `true # c` ; P'
```

The Q258 row named this shape as Q254's mechanism met in a script body. Q254
fixed the comment rule; the shape still defers because of the escapes, which
is this row. workspace-guard and exit-status-guard defer on both rows of the
table, with or without the `#`, and were not looked into further.

## Which way it gets built

Remove the escapes bash removes from an unquoted heredoc body -- a backslash
before `` ` ``, `$`, `\` or a newline -- before prod-guard reads the body as a
script. All four were driven on 5.3.15: `cat` given a body of
`` a\\b \$x \`c\` d\ `` and a second line `e` prints ``a\b $x `c` de``. A quoted heredoc is already left alone and must stay so.

## If it is never built

One comment in an escaped backtick substitution inside an unquoted
`bash <<EOF` body hides the rest of that line from prod-guard. How often
sessions write that shape is not measured; flat cost of delay.
