# workspace-guard's report files its mixed-command deny under other

The suppression escalation's reason, `plugins/workspace-guard/scripts/bash-workspace-guard.py:This command mixes a guarded command with`, matches no entry in the report's `REASON_PATTERNS`.
Each one is ranked as `other`, which the report explains as another guard's prompt.

Measured 2026-11-24 with the denial fix in place: 22 of the 118 denials in the last seven days, all with this wording.
The wording key could not recover them at all, so they were missing from the report rather than miscounted until it read the opener behind Claude Code's prefix.

## Which way it gets built

Add the pattern, detection-only because the reason names no path token, and a test that builds the reason from the hook rather than copying it.
A test asserting that every reason the hook can emit lands in a named category would have caught this one, and is the better shape if the hook's reasons can be enumerated cheaply.
