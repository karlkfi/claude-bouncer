# A watch in a double-quoted substitution runs in the foreground unseen

`tokenize` rewrites every backtick to `;` before lexing, so an unquoted
substitution splits into its own segment. Inside double quotes the rewritten
`;` lands in a quoted word, shlex keeps the word whole, and the substituted
command is never classified. `$(...)` fails the same way, because `(` is
punctuation only outside quotes. Bash runs all of these, and in the
foreground: the enclosing command waits on the substitution.

Measured 2026-10-01 at `b27be8d` by driving the hook with a JSON payload, cwd
the repo root:

| command | guard |
|---|---|
| `gh run watch 456` | deny -- control |
| `` echo `gh run watch 456` `` | deny -- control |
| `` echo "`gh run watch 456`" `` | **defer** |
| `echo "$(gh run watch 456)"` | **defer** |
| `X="$(gh run watch 456)"` | **defer** |
| unquoted heredoc body, `x = '$(gh run watch 456)'` | **defer** |
| `echo '$(gh run watch 456)'` | defer -- correct, single quotes keep it literal |

That bash runs each double-quoted shape was driven for the prod-guard twin of
this row, with a payload absent from `PATH` under
`env -i bash --norc --noprofile -c`; a quoted heredoc body runs its
substitutions too, since quote characters there are literal text. The same
probe found workspace-guard correct on every shape, because it already scans
with `command_substitutions`.

## Which way it gets built

The prod-guard fix for Q196 is the model: find substitutions structurally with
`command_substitutions(text, quotes=True)` from `lib/bouncer_parse.py`, and
tokenize each body as its own segments, ahead of the command that holds it.
The heredoc case is the second half. This guard strips heredoc bodies before
tokenizing and its `CLAUDE.md` forbids parsing a body as command segments,
which is right for the body's words and wrong for its substitutions: scan an
unquoted-delimiter body with `quotes=False` and judge only what that returns.

A hoisted segment carries no `&` terminator of its own, so the backgrounding
check needs a decision: a substitution inside a backgrounded command does not
block the main thread, and it should inherit the enclosing segment's
terminator rather than read as foreground.

## If it is never built

A watch or a long `sleep` written inside double quotes parks the main thread
with no deny. The cost is waiting rather than an outage, which is why this
ranks below the security rows, and the shape is the ordinary one for capturing
a command's output into a variable.
