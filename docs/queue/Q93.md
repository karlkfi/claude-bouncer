# Publish the backlog index, which a directory listing does not give

`docs/queue/` sorts Q10 before Q2 on github.com, so a reader browsing the repo
has no priority order. `make backlog` covers a local checkout only, and the
rendered table must never be committed — it is the one file every completing
session would edit, so a tracked copy undoes the layout.

The repo went public on 2026-08-22, which puts GitHub Pages back on the table:
it needs no paid plan on a public repo, and `gh api
repos/karlkfi/claude-bouncer/pages` returning 404 the same day means no site is
configured rather than none is allowed. Nothing else publishes here, so a deploy
takes the one Pages site a repo gets without displacing anything.

Render `queue.py render --format table --all` into the page as a build step and
gitignore the path it lands on. The CI job summary is the fallback if a site is
more than this earns — it works either way and needs no deploy, but a reader has
to know to look in Actions.
