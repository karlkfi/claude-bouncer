# A git command after an unfollowed cd reads the session's branch

`cd "$X" && git commit -m x`, a `git` command after a `cd` the hook can't
follow, is judged as if the commit ran in the session's
own checkout, so the branch it lands on is never read. Today the command defers
(the `cd` is a non-git segment), but a commit there in a session that has
allowlisted `git commit` lands wherever `$X` points, including another
checkout's `main`. Q331 closed the same fallback for a repository named on the
git command itself (`--git-dir`, `GIT_DIR`, a non-literal `-C`) and left this
half alone on purpose:
`plugins/branch-guard/hooks/branch-guard.py:3337:head_cwd = inv_cwd or invocation_cwd(seg_cwd or cwd, inv, True)`
starts the HEAD walk from the session's directory when a `cd` left it unknown.

A variable exported earlier in the command reaches the same fallback:
`export GIT_DIR=../other/.git && git commit`, its `;` form and `declare -x`
all defer on Q331's head, and in git 2.55 each commit landed on the sibling's
`main` (measured by Q331's reviewer; frequency unmeasured). The `bash -c` body
spelling is Q297's.

The obvious fix is too expensive as it stands. Replayed 2026-11-01 from this
machine's transcripts (2,675 distinct commands carrying a redirect and a
branch-sensitive verb, out of 245,092 Bash calls), asking on every directory
the hook can't name moved 1,280 commands from no decision to an ask; Q331's
narrower fix still moves 64, so this half is the other 1,216. By the first
redirect each of the 1,280 matched, 1,007 open with
`cd "$(git rev-parse --show-toplevel)"`, 195 with `cd $var` and 8 with
`cd "$(pwd)"`; the categories overlap, so they need not sum to 1,216.
`cd_destination` gives up on both
(`plugins/branch-guard/hooks/branch-guard.py:1561:if not is_literal_path(t):`),
though each names a directory the hook can compute: workspace-guard already
resolves exactly those two substitutions in its own `cd` tracker.

Next step: have `cd_destination` resolve those two forms against the segment's
directory, then re-run the replay and decide on the residue (the `cd $var`
and exported-variable forms) whether a `cd` the hook still can't follow
should ask on the branch-sensitive verbs the way Q331's redirects do.
