# Reads of bundled skills, Go source and side-session notes all ask

Three read-only trees outside the project root prompt on every read, and the
maintainer approves every one. Measured from 2026-09-25 to 2026-10-25: about 34
asks, mostly in github-actions-gateway. Go stdlib and toolchain source 16,
bundled skills 11, the app's side-session notes under `~/Library` 7. Each tree
re-driven 2026-10-25 against 1.13.0 asks on a plain `cat`. A fourth, sibling
sessions' scratchpads (17 asks), was a bug in the same-project exemption and
was fixed on its own.

## Why each one asks

- **Bundled skills** live at `<tmp_root>/bundled-skills/<cc-version>/<hash>/`.
  They are under the Claude temp root but carry no session id, so neither temp
  exemption applies, and they are not under `~/.claude/skills/`
  (`plugins/workspace-guard/scripts/bash-workspace-guard.py:342:for name in ('plugins', 'skills'):`).
  Claude Code itself writes them, on the same trust footing as
  `~/.claude/plugins/`.
- **Go source** is `$(go env GOROOT)/src` (`/usr/local/go/src` here) and the
  toolchain module cache, `~/go/pkg/mod/golang.org/toolchain@*/src`. Vendoring
  is the usual answer for dependency source, and it does not reach the
  standard library.
- **Side-session notes** are
  `~/Library/Application Support/Claude/side-session-notes/<family>/`. The
  desktop app adds this folder to the session as an additional working
  directory, and the guard does not know that. The hook input does not carry
  it: in Claude Code 2.1.308 the common hook fields are `session_id`,
  `transcript_path`, `cwd`, `scratchpad_dir`, `prompt_id`, `permission_mode`,
  `agent_id`, `agent_type` and `effort`, read 2026-10-25 from the function
  that builds them in the desktop app's binary. `additional_directories`
  appears only in SDK init and session-claim messages. Not a captured payload:
  the CLI's login had expired, so no headless run could fire a hook.

## Which way it gets built

Read-only defaults in `allowed_read_prefixes`, one per tree, with writes
unchanged:

- Add `<tmp_root>/bundled-skills/` beside `claude_code_dirs()`.
- Add the Go toolchain roots only when `go` is on `PATH`, read from
  `go env GOROOT GOMODCACHE` at hook time. If that costs too much per call,
  leave it to `WORKSPACE_GUARD_READ_ALLOW_PREFIXES` and document the line.
- Side-session notes: the hook input names no additional working
  directories, so add the app's notes root as a default.

**If never built:** about 34 approved prompts a month, concentrated in the
orchestrated runs this audit set out to quiet.
