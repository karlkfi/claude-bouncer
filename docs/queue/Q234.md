# exit-status-guard reads `time -p` as the command and loses the deny

`time` is a bash reserved word, so the shared `strip_sh_keywords` drops it
(`lib/bouncer_parse.py:107:    'if', 'then', 'elif', 'else', 'while', 'until', 'do', 'time',`)
and leaves its `-p` as the command word. The registry pattern then does not
match, and a gate piped into a filter goes through. Q222 taught
`peel_wrappers` to take a wrapper's options off with it, but only for words in
`WRAPPERS`, and `time` never gets there: the keyword is gone before the
wrapper check runs
(`plugins/exit-status-guard/scripts/bash-exit-status-guard.py:318:        tokens = strip_env_prefix(strip_sh_keywords(tokens))`).

Measured 2026-10-04 on the Q222 branch, by driving each hook with a JSON
payload:

| guard, control | bare | `time` | `time -p` |
|---|---|---|---|
| exit-status-guard, `make check \| tail -5` | deny | deny | **silent** |
| prod-guard, `kubectl --context=prod delete pod x` | deny | deny | deny |
| foreground-guard, `tail -f log.txt` | deny | deny | deny |

The other two guards already read through it, so the fix lands in this guard
and not in `lib/`.

Driven under `env -i "$(command -v bash)"` 5.3.15: `time -p false` exits 1, so
the timed command's status is what a pipe would swallow. bash takes exactly
`-p` there: `time -- true` runs `true`, and `time -pp true` runs a command
called `-pp`.

## Which way it gets built

Drop a `-p` (and a `--`) that directly follows an unquoted `time` before
`peel_wrappers` goes on. Doing that needs the token list from before
`strip_sh_keywords` ran, because afterwards nothing says `time` was ever there.
Read how prod-guard and foreground-guard do it first, since both already pass.

## Who it is for, and what happens if it is never built

Anyone timing a gate with POSIX output, such as `time -p make check | tail`.
This is rare in agent-written commands, which is why it ranks below the
wrapper rows. Left alone, that spelling loses its exit status with no deny.

The README and the module docstring say a command wrapper's options are
peeled, and they name `time` among the peeled wrappers without promising that
its options come off. A fix here lets them say so.
