# Nothing pins Ctx to one construction site, and the posture needs it

`Ctx` carries `cat_actions`, the per-category `deny`/`ask` map Q84's supervising
posture reads
(`plugins/workspace-guard/scripts/bash-workspace-guard.py:3058:return Ctx(`).
The field has a default of `None`, so a `Ctx` built without it is legal, and
`decide()` reads `None` as every category denying.

That default is unreachable today. Measured on trunk `950bda9`, over
`plugins/workspace-guard/scripts/bash-workspace-guard.py`:

    Ctx(          1 hit, line 3058, inside build_context
    _replace      0
    _make         0   (2 substring hits, both `ps_new_item_makes_link`)
    copy/deepcopy 0
    ctx._ / Ctx._ 0

All four `decide()` call sites take their context from that one builder, so
every `Ctx` reaching a verdict has the field populated. The `_replace` and
`_make` checks are the load-bearing half: "one `Ctx(` call" does not on its own
establish unreachability, because a namedtuple can be rebuilt without a
constructor call.

**Who it is for.** The next person to add a second construction site — a new
frontend, a handler that wants a tweaked context. Nothing tells them
`cat_actions` exists, and the failure is invisible at the moment they make it.

**What breaks, and it is not the boundary.** A forgotten field denies:
`actions.get(c, 'deny')` returns `deny`, `cross_deny` goes true, the command is
refused. So the guard stays closed and what stops working is the *opt-in* — an
operator running `WORKSPACE_GUARD_POSTURE=supervise` gets denials while
believing they are watching prompts, on whichever frontend got the new site.
Rank it as a broken feature rather than a security regression; the obvious
framing ("a posture can stop applying") reads like the latter and would
out-rank its actual cost.

**Which way it gets built.** A test, not a comment. The hazard is a future
edit, and a comment cannot bind one — this repository has already made that
call twice, in `make path-filter-check` and `make action-pin-check`, both
structural recurrence guards for defects a convention could not hold. The
general form: a rule that must hold *every time* cannot live in prose, and the
tell is that the failure is invisible as it happens.

Assert over the script's source that there is exactly one `Ctx(` construction
and no `_replace`, with the reason in the test's docstring so whoever trips it
learns that the field is the point rather than deleting the assertion. A
structural test is the honest shape here: the invariant is about the *set of
construction sites*, which no runtime assertion over one context can see.

**If it is never built,** the posture keeps working until the day someone adds
a second site, and then stops working silently for whoever is relying on it.

Filed at the tail deliberately: this came out of Q84's review with no ranking
against the rest of the store, and the next groom places it.
