# A command held in a variable the guard resolved is never re-read

`X="kubectl …"; eval "$X"` is an ordinary scripting idiom, and bash runs the command the variable holds. prod-guard resolves `X` and then judges the result as one word: the `eval` body is built from the unexpanded operands, so the nested string is the single token `$X`, which expands to one command name holding spaces, and no evaluator matches it.
A bare `$X` in command position fails the same way, because the expanded value is never word-split.
The mechanism is read from the source, not traced.

Measured 2026-11-17 on `main` at `a3a43e4d` with the fixture `$HOME`, whose current context is `gke_acme_prod-us`. bash 5.3.15 under `env -i /opt/homebrew/bin/bash --norc --noprofile`, with `/bin/echo RAN` in place of kubectl, printed `RAN` for each of the `eval "$X"`, `eval $X` and `$X` forms:

| command | prod-guard |
|---|---|
| `kubectl --context gke_acme_prod-us delete ns x` (control) | deny |
| `eval "kubectl --context gke_acme_prod-us delete ns x"` (control) | deny |
| `X="kubectl --context gke_acme_prod-us delete ns x"; bash -c "$X"` (control) | deny |
| `X="kubectl --context gke_acme_prod-us delete ns x"; eval "$X"` | **defer** |
| `X="kubectl --context gke_acme_prod-us delete ns x"; eval $X` | **defer** |
| `export X="kubectl --context gke_acme_prod-us delete ns x"; eval "$X"` | **defer** |
| `X="kubectl --context gke_acme_prod-us delete ns x"; $X` | **defer** |

Not Q279: that row covers a command word the guard cannot resolve, and here the value is assigned in the same string and resolved.
Found while working Q377.

## Which way it gets built

Build the `eval` body from the expanded operands rather than the raw ones, so the nested evaluation tokenizes the text bash would evaluate.
For a bare `$X` command word, split the expanded value on whitespace the way an unquoted expansion is split, and judge the words that result. `bash -c "$X"` already denies, because its body is expanded before it is read, so that branch is the model.
Not measured.

## If it is never built

A production mutation stored in a variable and run through `eval` or a bare expansion runs without a prompt.
