# A variable reassigned later in a loop body keeps its first value

The hook reads a loop body once, top to bottom, so a use above a reassignment is judged only against the value from before the loop. bash runs the body again with the new value.

Measured 2026-11-24 on `main` at `de050f70`, with the hook run against this checkout:

| command | verdict |
|---|---|
| `D=/etc/q8-fake; cat "$D/x"` (control) | ask |
| `D=./a; for i in 1 2; do cat "$D/x"; D=/etc/q8-fake; done` | **allow** |

Next step: at a `for`, `while` or `until`, drop from `varmap` every name its body assigns before judging the body, so the use denies as runtime-expanded.
`while` and `until` were not measured.

## If it is never built

A loop that moves a path variable outside the project on its first pass reads or writes there on the second with no prompt.
