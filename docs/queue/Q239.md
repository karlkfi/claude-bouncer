# foreground-guard reads `&` before a newline as foreground

`tokenize` rewrites each newline to `;` before lexing, and shlex groups a run
of punctuation characters into one token, so `&` directly followed by a
newline comes out as the single token `&;`. Both background checks compare
against exactly `&`: the whole-command check in `analyze_class_a`
(`plugins/foreground-guard/scripts/bash-foreground-guard.py:730:if tokens and tokens[-1] == '&'`)
reads the last token, and the per-segment one
(`plugins/foreground-guard/scripts/bash-foreground-guard.py:752:bg = (term == '&')`)
reads the terminator `split_segments` recorded. A backgrounded wait written on
its own line therefore reads as foreground and denies.

## Measured

2026-10-04, against `origin/main` at `442c86e`, driving the hook with a JSON
payload:

| command | guard |
|---|---|
| `sleep 300 & ls` | defer -- control |
| `sleep 300 &   \nls` | defer -- control, a space separates the two |
| `sleep 300 &\nls` | **deny** |
| `sleep 300 &\n\nls` | **deny** |
| `gh run watch 1 &\n` | **deny** |

That bash backgrounds the job either way was driven under
`env -i "$(command -v bash)" --norc --noprofile -c` (GNU bash 5.3.15):
`s=$SECONDS; sleep 2 &` then a newline then `echo $((SECONDS-s))` printed
`0`.

Found while working Q220. That fix judges a substitution under the
backgrounding of the segment holding it, so it inherits this defect: a
substitution in a backgrounded command written on its own line is judged as
foreground.

## Which way it gets built

Rewrite a newline to `;` only where it does not follow `&`, or split a
punctuation token that mixes `&` and `;` back into its operators before
`split_segments` reads it. `split_segments` and the trailing-`&` check both
have to see the plain `&`. Keep `&&`, `|&` and a quoted `&` (Q203) as they
are.

## If it is never built

A backgrounded server, poll or long `sleep` written as its own line of a
multi-line command is denied as if it blocked. The agent can work around it
by putting a space after the `&` or joining the lines, but nothing tells it
to, and CLAUDE.md lists backgrounded segments among the forms that must defer
silently.
