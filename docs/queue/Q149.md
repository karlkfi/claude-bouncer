# An interpreter option that takes an argument silences Class B

Class B peels the interpreter's options without reading any of them
(`plugins/foreground-guard/scripts/bash-foreground-guard.py:696:while argv and argv[0].startswith('-')`),
so an option that takes a *separate* argument leaves that argument standing as
the command word. The registered script is then one token to its right, where
`runs_command` requires the match to begin inside the command word, and the
segment matches nothing.

Measured 2026-09-01 against this tree with the README's own registration,
`{"scripts/gate\\.sh": 3600000}`: `bash -o errexit scripts/gate.sh`,
`bash -o pipefail scripts/gate.sh`, `bash --rcfile /dev/null scripts/gate.sh`
and `bash -O extglob scripts/gate.sh` all defer, where the control
`bash scripts/gate.sh` denies. Every one of those four runs the gate.

Q138 named the `-o noexec` instance of this and scoped it out, reading it as a
false negative that happens to land on the right answer — a parse-only run
should defer. That reading is correct for `noexec` and it is the benign member
of the class. The other options in the same position are the defect: the guard
goes quiet on a command that really does block for an hour.

**Who is worse off.** Whoever registered the gate. The guard's value is that
its findings are always real, and the converse it trades on is that silence
means the command is safe to run in the foreground. Here silence means the
reducer lost the command word. Rate is low — it needs an interpreter option
that takes an argument, which few sessions write — but it is silent in both
directions, so nothing reports the miss and no friction report can count it.

**Which way it gets built.** The peel has to know each option's arity, so it
needs a small table of the interpreter options that consume a following word
(`-c`, `-o`, `+o`, `-O`, `+O`, `--rcfile`, `--init-file`) and it should skip
two tokens for those and one otherwise. Stopping at `--` and at the first
non-option is already right. Do not widen `runs_command` instead: the command
position is what separates running a script from naming it (#16), and relaxing
it re-opens that.

**If it is never built,** a registered slow gate invoked through any of those
forms runs unguarded, and the reducer keeps a shape where being wrong about the
command word produces no signal at all.
