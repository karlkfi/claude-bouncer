# `metrics` reads the squash subject, so completions count as nothing

Invariant 4 of
[`maintaining-backlog.md`](../development/maintaining-backlog.md) asks a
completing session to name the reason with a fixed verb -- `complete QN`,
`prune QN`, `merge QN into QM`, `defer QN` -- because a deleted item file looks
identical in the diff whatever the reason, and the verb is what lets
`queue.py metrics` tell throughput from garbage collection.

Sessions follow it, and the report is empty anyway. Measured 2026-08-23:

    filed 47   completed 0   pruned 0   open 30
    cycle time median 0d     prune ratio 0%

Seventeen items have been removed from the store and not one is attributed.

**The verb is on `main`; the walk does not look where it lands.**
`mergeCommitAllowed` is false on this repository, so every pull request arrives
as one squash commit whose *subject* is the pull request title. GitHub keeps the
branch's own subjects as bullets in the squash **body**, so the verb survives
the merge intact -- `4fe8030` carries
`* docs(queue): complete Q76, file Q114 for the -Recurse question` under a
subject that says `fix(workspace-guard): judge a PowerShell unlink by the link`.
`scripts/queue.py:690:"--pretty=format:C\t%H\t%ad\t%s", "--", str(rel)], root)`
asks git for `%s` alone, and
`scripts/queue.py:708:verb = re.search(r"\b(complete|prune|merge|defer)\w*\b",`
then searches a string the verb was never in.

So this is a one-specifier defect rather than a process failure, which is worth
saying plainly: the discipline the invariant asks for has been honoured on every
one of those seventeen removals.

Two things to get right when changing it. **Read `%B`, not `%b`** -- the subject
is the first line of the body and a completion filed in its own pull request
keeps the verb there, so dropping the subject would trade one blind spot for
another. And **key the search on the item's own ID**, because a squash body
holds a bullet per branch commit and may name several items with different
verbs: `4fe8030` says `complete Q76, file Q114` in one line, and a search for a
bare verb would hand Q114 a completion it never had.

Land it in `karlkfi/claude-skills` first and re-vendor, per the hazard Q97
names -- a fix made in `scripts/queue.py` alone is reverted by the next vendor
drop.
