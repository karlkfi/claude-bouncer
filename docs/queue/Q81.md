# Track `case` patterns so their `)` does not end a substitution early

Measured 2026-08-20 on the 169 fix: a `case` pattern's `)` inside `"$(…)"` ends the substitution early, so an odd-quote heredoc body there is still silent. Needs `case`/`esac` tracking.
