# Track `case` patterns so their `)` does not end a substitution early

Measured 2026-08-20 on the 169 fix: a `case` pattern's `)` inside `"$(…)"` ends the substitution early, so an odd-quote heredoc body there is still silent. Needs `case`/`esac` tracking.

The fix lands in `_scan_dollar_paren`, which tracks quotes and backslashes but not `case`/`esac` — so it is a `lib/bouncer_parse.py` change reaching all five guards, not a workspace-guard one. `workspace-guard` stays on the row because the measurement is there and so is the natural fixture. Re-run every suite, and `make sync` before you do.
