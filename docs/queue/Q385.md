# An env -S string is expanded against the shell, not env's environment

`env -S 'STRING'` expands `${NAME}` in its string itself, against its own
environment, which holds only what the shell exported plus env's own
`NAME=value` operands. prod-guard expands the single-quoted string in the
parent, against every shell variable, exported or not, so a name assigned
without `export` resolves to a value env never sees. env then hands the
command an empty value. Mechanism read from the source, not traced: the
string reaches `env_split_string` already expanded by `expand_argv`.

Measured 2026-11-17 on `main` at `3991c85e`, with the fixture `$HOME` whose
current context is `gke_acme_prod-us`. In bash 5.3.15 under `env -i
/opt/homebrew/bin/bash --norc --noprofile`, `CTX=kind-dev; /usr/bin/env -S
"/bin/echo [\${CTX}]"` printed `[]`, `export CTX` first printed `[kind-dev]`,
and a `CTX=x` prefix printed `[x]`:

| command | prod-guard | what kubectl gets |
|---|---|---|
| `export CTX=kind-dev; env -S 'kubectl --context=${CTX} delete pod x'` (control) | defer | `kind-dev` |
| `CTX=kind-dev env -S 'kubectl --context=${CTX} delete pod x'` (control) | defer | `kind-dev` |
| `CTX=kind-dev; env -S 'kubectl --context=${CTX} delete pod x'` | **defer** | empty, the current context |
| `CTX=gke_acme_prod-us; env -S 'kubectl --context=${CTX} delete pod x'` | deny | empty, the current context |

Found while working Q365, whose fix keeps a single-quoted assignment value
literal and deliberately leaves an `env -S` string to this expansion.

## Which way it gets built

In the `env -S` branch of `strip_wrappers`, expand a word the shell left
alone against `child`, env's environment, rather than taking the parent's
expansion. A word the parent did expand, written in double quotes, must keep
the parent's reading: there `${CTX}` was already replaced, and with an unset
`CTX` the guard holds it as an unresolved name, which `child` must not fill
in. Telling the two apart needs the word's quoting at that point, which the
expanded argv no longer carries. Not measured.

## If it is never built

A mutation behind `env -S` whose target names an unexported shell variable
runs against the current context with no prompt when that variable holds a
nonprod value.
