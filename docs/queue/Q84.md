# Offer a `supervise` posture that turns denies back into prompts

An operator building trust in the guard can't watch it work short of downgrading it. `hook-verdict` prescribes an opt-in `WORKSPACE_GUARD_POSTURE=supervise`; the default stays unsupervised.
