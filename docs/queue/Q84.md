# Offer a `supervise` posture that turns denies back into prompts

Half of it already ships. `WORKSPACE_GUARD_TMP_ACTION=ask` softens the host-temp
deny to a prompt
(`plugins/workspace-guard/scripts/bash-workspace-guard.py:627:v = (os.environ.get('WORKSPACE_GUARD_TMP_ACTION') or 'deny').strip().lower()`),
which is this posture wired for one category. Measured 2026-08-24 over 1,160
local transcripts: of 146 recovered workspace-guard denies the reasons carry
`hosttemp` 76 times, so the knob that exists already covers most of the traffic.
What a new posture newly reaches is `sibling` (9) and `kill` (5), with
`crosssession` at zero.

**Who it is for.** An operator deciding whether to keep the deny defaults. The
guard denies rather than asks on the cross-checkout classes because they
self-heal in one agent round trip, and nothing lets that operator watch those
denies land as prompts before believing it. `WORKSPACE_GUARD_OVERRIDE` is not
that: it is per-command and it stands the guard aside instead of showing you the
decision.

**Which way it gets built.** Follow the knob already in the file rather than
`hook-verdict`'s single switch — a per-category action defaulting to `deny`, with
`WORKSPACE_GUARD_POSTURE=supervise` as the all-categories spelling above it. The
plugin's own security rule sanctions the shape: the looser behaviour ships as an
explicit opt-in and the secure default does not move.

**It has to be mode-aware, and this row did not say so.** An `ask` blocks in
every mode but only reaches a person in the attended ones, so a supervised `ask`
where nobody can answer strands the agent behind a prompt. `bypassPermissions` is
already handled — `deny_now = bypass or …` forces the deny, so a posture belongs
*under* that `or`, not over it. `dontAsk` is the gap: the matrix has `ask`
blocking there too, and foreground-guard treats it as unattended for exactly this
reason.

**If it is never built,** the deny classes stay unwatchable, and every argument
for them stays a claim the operator has to take on trust.

`S` holds and shrinks: the pattern, the default and the `bypassPermissions`
fallback are all present, so the work is three categories reading a knob plus a
`dontAsk` check. Rank `a7` does not hold — it is 7th, it newly reaches 14 denies
in 1,160 transcripts against a knob already covering 76, and nothing is blocked
on it. It belongs below Q87, at the foot of the workspace-guard group.
