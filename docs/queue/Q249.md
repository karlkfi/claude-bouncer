# workspace-guard's report reads a launcher-wired guard as 100% deny

workspace-guard's copy of the friction report labels a hook decision by the
`*.py` its hook command names
(`plugins/workspace-guard/scripts/friction-report.py:248:    m = re.search(r'([A-Za-z0-9_-]+)\.py', command or '')`),
and reads denies off the reason opener. spill-guard is wired
`"${CLAUDE_PLUGIN_ROOT}/hooks/run-spill-guard.cmd" hook`, with no `.py` named.
So its asks and silent defers drop out of the attachment stream while its
denies are still counted, and the report shows a 100% deny rate.

Measured 2026-10-04 over 90 days of this machine's transcripts:

    python3 plugins/workspace-guard/scripts/friction-report.py --plugin spill-guard --since 90d

    Guard decisions analyzed: 693
      plugins: spill-guard 693
      outcomes: deny 693

foreground-guard's copy, run with Q207's fix over the same window, records
3,823 spill-guard decisions: 3,052 defers, 686 denies and 85 asks.

Q207 fixed this in foreground-guard alone, on the premise that its copy was the
only one with a cross-guard view. That premise was wrong for workspace-guard.
In the same run, exit-status-guard's and prod-guard's copies do not report
spill-guard at all, so they show nothing rather than a false rate. Not judged
here: exit-status-guard's copy also lists `pr-sentinel-guard` and `pr-sentinel`
as two plugins, the split foreground-guard's copy folds.

## Which way it gets built

Port Q207's rule into workspace-guard's `guard_name`. Search for the `.py`
first, fall back to the launcher's basename less its extension and a `run-`
prefix, and keep that label only where it ends in `-guard` or is a listed
non-guard plugin. foreground-guard's `GuardNameTests` and `NameAgreementTests`
are the cases to carry over. The copies are not vendored, so this is a port
rather than a shared change.

## If it is never built

Anyone reading workspace-guard's cross-guard report sees spill-guard, and any
other guard wired through its own launcher, as denying every call it judges.
That reading looks like a measurement, so it is acted on.
