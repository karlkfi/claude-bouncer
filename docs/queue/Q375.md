# A hash in a double-quoted arithmetic hides the commands after it

`echo "$(( 1 # ))`, a newline, then `) ; P)"` runs `P`, and no guard judges it.
Under `env -i /opt/homebrew/bin/bash --norc --noprofile -c` (5.3.15), the
command with `P` replaced by `echo RAN` prints `1: command not found` and then
`RAN`. Inside double quotes bash reads ` # ))` as a comment that runs to the
newline. The `$((` therefore never closes on `))`, and bash reads it as `$( (`,
a substitution whose body is the subshell `( 1 )` followed by `; P`. Unquoted,
the same text closes at the first `))` and fails as a syntax error.

The parser has no comment rule inside arithmetic. `_arith_end` closes the
`$((` at the first `))`, and `P` is left as text in the outer double-quoted
word. Fed to each hook as a `PreToolUse` payload, with `P` as each guard's
stand-in, every guard defers on `main` at `36d05ed8` and on #348's head. The
plain form `echo "$( ( 1 ) ; P)"` gets deny from prod-guard, ask from
workspace-guard, deny from exit-status-guard and deny from foreground-guard.
branch-guard deferred on both forms with `git push --force origin main` in a
scratch payload, so that probe says nothing about branch-guard either way.

The #348 reviewer found it (comment 6940409850 on that PR). #348 scoped the
rule in `_arith_end`'s docstring to unquoted text, at
`lib/bouncer_parse.py:1140:``${…}`` is. Unquoted, a ``#`` starts no comment. In double quotes bash`.
Neither tree returns a body for the quoted form, so the gap predates #348.

## Which way it gets built

Make `_arith_end` comment-aware when the `$((` sits inside double quotes. A
` #` at a word start runs to the newline, as `_scan_dollar_paren` already
treats one. Where that leaves no `))` close, the existing fallback reads the
text as `$( (`. Before building, measure how far bash's rule reaches: whether a
`#` glued to a word counts, whether a bare `((` in a double-quoted `$(…)`
follows it, and whether an unclosed comment changes the close. None of that
has been measured. Pin the command above as a parser test, and as a verdict in
each guard's suite.

## If it is never built

A command written after a quoted arithmetic holding ` #` and a newline runs
past every guard. Nobody writes the shape by accident, so it is reached only
by a command built to get past them.
