# foreground-guard's substitution pipe check sees only the job's redirects

Q363 decides whether a job backgrounded inside `$( )` still holds the substitution's pipe by reading that job's own redirects, in order.
The shell also carries descriptor state the segment does not show: an earlier `exec` in the body, a redirect on an enclosing loop or group, the `time` keyword's subshell, and a `bash -c` body's outer redirect.
Each misjudges in a fixed direction.

Found by the stream reviewer on the Q363 pull request, #406, at `908a285`, in its review comment there.
Re-measured 2026-11-27 with `env -i /opt/homebrew/bin/bash --norc --noprofile -c` (GNU bash 5.3.15), a 1 s sleep, and the hook on the Q430 branch at `5c3f160` with a 30 s one:

| command | bash | foreground-guard | wrong way |
|---|---|---|---|
| `x=$(time sleep 1 >/dev/null &)` | 1.06 s | none | misses a wait |
| `x=$(exec 3>&1; sleep 1 >/dev/null &)` | 1.05 s | none | misses a wait |
| `x=$(for i in 1; do sleep 1; done >/dev/null &)` | 0.04 s | deny | false deny |
| `x=$(exec >/dev/null; sleep 1 &)` | 0.04 s | deny | false deny |
| `x=$(bash -c 'sleep 1 &' >/dev/null)` | 0.05 s | deny | false deny |

The #406 body also names two false denies from the same class: `x=$(sleep 1 >/dev/null | true &)` at 0.39 s, and `x=$( { sleep 1 & } >/dev/null )` at 0.03 s.

## Which way it gets built

Carry descriptor state through the body rather than per segment: an `exec` redirect changes it for every later segment, a compound's trailing redirect applies to everything inside it, and `time` in front of a backgrounded command makes the job a subshell like `&&` does.
A `bash -c` body would take its `piped` from the outer command's own redirects instead of inheriting it unconditionally.
Not measured, and possibly larger than `S`: the compound redirect needs the closer's redirects before the segments inside it are judged.

## If it is never built

The two misses let a rare `$(... &)` wait through with no deny.
The false denies cost one retry each, on shapes the drives above had to construct.
How often sessions write any of them is not measured.
