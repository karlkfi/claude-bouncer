# A quoted `&` reads as backgrounding, so a foreground command runs

`split_segments` records the punctuation token that ended each segment as
that segment's operator --
`plugins/foreground-guard/scripts/bash-foreground-guard.py:305:if t and all(c in PUNCT_CHARS for c in t)`
-- and reads the token's text alone. A quoted or escaped `&` is a word bash
passes to the command, so `sleep 300 '&'` runs in the foreground and the
guard reads it as backgrounded and stands down.

That is the fail-open direction for this guard, whose whole job is to deny a
command that parks the main thread. The docstring's argument -- crude
splitting "only ever creates extra segments to inspect, never hides a
watch/sleep command behind an operator" -- holds for the segment boundary and
not for the operator the boundary is recorded as.

## Measured

2026-09-10, driving `PreToolUse` payloads at the hook:

| command | verdict |
|---|---|
| `sleep 300` | **deny**, parks the main thread for ~300 s |
| `sleep 300 &` | no decision (correctly backgrounded) |
| `sleep 300 ';'` | **deny** (a quoted `;` is not an operator either, and here that lands safe) |
| `sleep 300 '&'` | **no decision** -- read as backgrounded, runs in the foreground |

## Reachability is the weak half

`sleep 300 '&'` does not sleep: `sleep` rejects `&` as a time interval and
exits. So the shape that reaches the fail-open is one bash would run in the
foreground *and* whose extra operand it tolerates -- a wrapper taking
positional arguments, not `sleep` itself. Worth fixing as a parse defect
rather than as a live escape.

## The fix

`is_operator` in `lib/bouncer_parse.py` -- vocab membership plus
`quoted_from is None` -- is the shared predicate for this question, added
2026-09-10 with the workspace-guard fix. foreground-guard keeps its own
`PUNCT_CHARS` and `REDIR` and its own segmenter on purpose, so the change is
the `quoted_from` test in this loop, not adopting the lib vocab. Confirm the
lexer here hands back `QuotedStr` tokens on the path that reaches
`split_segments` before relying on the record.
