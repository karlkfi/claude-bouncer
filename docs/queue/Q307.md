# An approval after a session grant expires never renews it

Once a session grant passes its 8-hour cap, approving the same override again
records nothing, so every later command in that session asks. The session
override promises one prompt per batch, and it delivers a prompt per command
for the rest of the session.

`record_grants` skips any target already in the file, expired or not
(`lib/bouncer_grants.py:93:            if t not in have:`). `load_grants` drops
the expired entry, so the guard asks; the approval runs the command; the
PostToolUse recorder sees the old entry and appends nothing. Reproduced
2026-10-25 against the root copy: record at t0, load at t0+9h is empty,
record again at t0+9h, load is still empty.

Measured over transcripts from 2026-09-25 to 2026-10-25: prod-guard asked 26
times on `PROD_GUARD_SESSION_OVERRIDE`, and 25 of those were one
github-actions-gateway session (`a7a0d65a`) against one dogfood context. Its
grant file still holds the first grant, timestamped 2026-10-13 01:55 UTC, and
the asks run from 15:27 that day and again on 2026-10-20. With renewal working,
that session would have asked about three times: once per batch, per target.
That figure is inferred from the grant timestamps, not replayed.

## Which way it gets built

Keep "the TTL never slides" for a grant that is still live: re-recording an
unexpired target must not extend it. An expired target is a new grant, so
replace its entry with a fresh timestamp and the new reason. One change in
`lib/`, then `make sync`. A test drives record, expire, re-record, load.

**Who it is for:** any session whose sanctioned batch outlives eight hours,
which a dogfood validation run regularly does. All three grant users go
through this function: prod-guard's targets, workspace-guard's decision
shapes, and branch-guard's worktree grants. The two opt-in ones are off by
default on this machine, so prod-guard is where it bites today.

**If never built:** every prod batch past the cap costs one prompt per command
until the session ends. That is roughly 20 prompts a month at the measured
rate.
