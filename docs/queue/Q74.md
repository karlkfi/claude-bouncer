# Escalate suppression in modes that pre-approve

Declining to vouch should protect in the modes that pre-approve, and today it does not. A withheld `allow` still runs under `auto`/`acceptEdits`/`bypassPermissions` ([matrix](../../plugins/workspace-guard/docs/permission-modes.md)). Escalating to `ask`/`deny` would block ~1,657 commands in `auto`, most routine heredocs — needs a narrower signal first.
