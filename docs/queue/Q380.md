# branch-guard never reads a backtick substitution's body

bash runs the command inside a backtick substitution, so ``echo `git commit -m x` `` commits. branch-guard's tokenizer keeps the whole substitution as one word, at `plugins/branch-guard/hooks/branch-guard.py:1009:    return split_separator_runs(lex(cmd))`: ``tokenize("echo `git commit -m x`")`` returns ``['echo', '`git commit -m x`']``, so no segment starts with `git` and the guard returns no decision.
The `$(…)` spelling is judged, but only because `(` is one of the lexer's operator characters, so `echo $(git commit -m x)` tokenizes as `['echo', '$', '(', 'git', 'commit', '-m', 'x', ')']` and the body reads as a segment of its own.
Nothing in branch-guard extracts a substitution body on purpose; `extract_command_substitutions` exists only to stop an `allow`.

Measured 2026-11-17 on `origin/main` at `a3a43e4d` in a fresh repository on `main`, with the harness described in Q349.
The other four guards judge every row with their own traps, except exit-status-guard on the `bash -c` row, whose body it does not read:

| command | branch-guard |
|---|---|
| `git commit -m x` -- control | ask |
| `echo $(git commit -m x)` | ask |
| ``echo `git commit -m x` `` | **defer** |
| ``echo "`git commit -m x`" `` | **defer** |
| ``bash -c "echo \`git commit -m x\`"`` | **defer** |

Found while measuring Q349, where it made branch-guard defer on every backtick row for a reason that has nothing to do with Q349's backslash.

## Which way it gets built

Take every body `lib`'s `command_substitutions` returns, backticks included, and judge it as a command of its own, the way the other four guards do.
That also makes the `$(…)` path deliberate rather than an accident of the operator set.
Q279 is a separate question, about a substitution in the command word, and this change does not settle it.

## If it is never built

Any git command branch-guard would ask about runs unjudged when it is written inside backticks.
Agents rarely put a mutating git command inside a substitution, so the shape is unlikely by accident.
Rate unmeasured.
