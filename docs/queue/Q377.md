# Forgetting a name after source drops a production value it held

When the guard cannot tell what a command did to a name, it forgets the name,
and a forgotten target asks. That is right for a nonprod value and a
downgrade for a production one: the command may have left the value alone, in
which case the mutation reaches production, and a deny becomes a prompt.

Two paths forget this way after a `source`. Q299 forgets every name at the
`source` itself, at
`plugins/prod-guard/scripts/bash-prod-guard.py:3450:            _unset(reassigned_names(tool, argv[1:])`,
and Q336 forgets every name at each later command the string did not define,
at
`plugins/prod-guard/scripts/bash-prod-guard.py:3598:        elif EVERY_NAME in functions:`.

Found by review-r2 on the Q336 pull request, comment 6940738434, and measured
2026-11-16 through the end-to-end hook with the fixture `$HOME`, `main` at
`d21b90f7` and the Q336 branch at `ae37983`:

| command | `main` | Q336 |
|---|---|---|
| `C=gke_acme_prod-us; kubectl --context $C delete ns x` (control) | deny | deny |
| `source x.sh; C=gke_acme_prod-us; f; kubectl --context $C delete ns x` | deny | ask |
| `source x.sh; C=gke_acme_prod-us; ls; kubectl --context $C delete ns x` | deny | ask |
| `C=gke_acme_prod-us; source x.sh; kubectl --context $C delete ns x` | ask | ask |
| `C=gke_acme_prod-us; read X; kubectl --context $C delete ns x` | deny | deny |

The Q336 rows moved from deny to ask with that change; the Q299 row has asked
since Q299.

## Which way it gets built

Keep the held value as one reading beside "unset", the union Q301 introduced
and Q321 reused, so a production value still denies and a nonprod one asks.
The obvious form does not work: the scopes start from the hook's whole
`os.environ`, at
`plugins/prod-guard/scripts/bash-prod-guard.py:3293:        exported = dict(os.environ)`,
so marking every held name forks past
`plugins/prod-guard/scripts/bash-prod-guard.py:1058:_READINGS_MAX = 8`,
and past that cap the guard forgets them all, which is today's ask. The
reading has to attach only to the names a later command reads. Not measured.

## If it is never built

A production target assigned around a `source` prompts instead of being
refused, so the user's confirmation is all that stands between the command and
production.
