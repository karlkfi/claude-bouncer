# The suppression escalation's ask is structurally ungrantable

An operator who turns session grants on and approves a suppression escalation
buys nothing: the identical command asks again, and every time after that. The
grant is never recorded and never matched, so the one mechanism that exists to
stop a guard re-asking a settled question cannot reach this prompt.

`plugins/workspace-guard/scripts/bash-workspace-guard.py:4317:finish(esc[0], esc[1], [], data)`
passes an empty offenders list, and
`plugins/workspace-guard/scripts/bash-workspace-guard.py:2999:def grant_shapes(offenders, cwd):`
returns None for one — so PostToolUse records nothing and the pre-check has
nothing to match. The PowerShell frontend does the same, in the `handle_*` body
that opens
`plugins/workspace-guard/scripts/bash-workspace-guard.py:5603:outside, guarded = ps_analyze_command(cmd, ctx, ctx.cwd,`.

Latent rather than firing today: `WORKSPACE_GUARD_SESSION_GRANTS` is unset on
this machine, so nobody has met it. It becomes real the moment grants are
turned on, and it fires on exactly the prompts an operator would most want to
grant once — a repeated wrapper idiom in a long session.

## What to evaluate

What a grant would even be keyed on is the question. An offender grant is keyed
on a target string; a suppression has no target, only a signal name and a
command string. Keying on the signal alone is far too broad — one approval
would silence every `sh -c` in the session. Keying on the normalized command
string is narrow and probably right, and it is a third grant shape beside the
two `bouncer_grants.py` already serves, so it belongs in the guard rather than
in `lib/` (see the split this repo's `CLAUDE.md` describes).

A legitimate answer is that this prompt should not be grantable, in which case
the row is a doc line saying so rather than code. Q211 cuts the firing rate
first, which changes how much this is worth.

**Settles:** read `grant_shapes` and the two existing grant semantics, then
decide whether a command-string-keyed shape is worth a third.
