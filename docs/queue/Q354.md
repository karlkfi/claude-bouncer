# A process substitution in the pattern slot hides the file after it

`grep -v <(echo x) /outside/f` and `awk <(echo '{print}') /outside/f` read the
file, and workspace-guard answers `allow`. bash hands the reader `/dev/fd/63` as
its pattern or program, so the next word is the file. The guard moves a process
substitution out of the word list with its operator, which lets the file take
the slot the substitution held, so it is read as the pattern.

Driven 2026-11-06 under bash 5.3.15 with a planted file: both print it.
`grep -f <(echo x) /outside/f` and `cat <(echo a) /outside/f` ask, since neither
has a slot for the file to fall into.

Bites rarely: the 35,111 distinct commands holding a substitution in this
machine's transcripts were not searched for this shape specifically. Each
occurrence is a silent read outside the workspace, and `allow` also
short-circuits the user's own permission settings.

## Which way it gets built

Keep a word in the slot: a constant no argument can spell, dropped from the
reader's operands before they are resolved. claude-spill-guard took that route,
so read its port before writing this one. A word left in the list reaches every
reader of a group, including the `for` loop binding and `classify_cd`, and each
has to be checked.
