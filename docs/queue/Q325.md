# A nested $( ) in double quotes in a $( ) body hides the rest of it

Inside double quotes, `_scan_dollar_paren` steps over a `${…}` or backtick
span (Q292) but not a nested `$(…)`
(`lib/bouncer_parse.py:851:            end = _brace_end(text, i) if text.startswith('${', i) else -1`).
A `"` inside the nested substitution then reads as the end of the outer quote,
and the `)` after it closes the body early. Under
`env -i /opt/homebrew/bin/bash --norc --noprofile -c`, which prints
`5.3.15(1)-release`, `echo "$(echo "$(echo ")")" ; echo P)"` prints `)` and
then `P`. `command_substitutions` returns `['echo "$(echo "']` for it.

Driven 2026-11-01 on `origin/main` at `1e4363f`, with `P` standing in for
prod-guard's `kubectl --context gke_acme_prod-us delete ns payments`,
workspace-guard's `rm /etc/probe-target`, exit-status-guard's
`make check | tail` and foreground-guard's `tail -f log.txt`:

| command | bash runs P | prod / ws / exit / fg |
|---|---|---|
| `echo "$(echo "$(echo ")")" ; P)"` | yes | **defer** ×4 |
| `echo "$(echo "$(echo a)" ; P)"`, the control | yes | deny / ask / deny / deny |
| `x=$(echo "$(echo ")")" ; P)`, unquoted outer | yes | deny / ask / deny / deny |

r-lib found it reviewing Q292 (#291). It predates that change.

## Which way it gets built

In the in-double branch, step over a `$(` with a recursive
`_scan_dollar_paren` and a `$((` with `_skip_balanced_parens`, beside the
`${…}` and backtick spans. `_brace_end` already makes the same two calls.

## If it is never built

A command after a nested `"$(… ")" …)"` inside a double-quoted `$( )` goes
unjudged by every guard. The shape needs a quote character inside the inner
substitution, so it is likely rare outside a deliberate attempt.
