# Two guards each merge command and process substitutions by hand

workspace-guard merges `command_substitutions` and `process_substitutions` into one ordered list of outermost bodies, dropping a `$( )` that sits inside a `<( )` (`plugins/workspace-guard/scripts/bash-workspace-guard.py:4895:def all_substitutions(text):`).
Since Q420, branch-guard does the same inline in `substitution_verdicts` (`plugins/branch-guard/hooks/branch-guard.py:3661:found = sorted(procs + [f for f in found`), and also carries each body's funsub flag, which workspace-guard's version drops.
The repo's rule is that a primitive moves into `lib/` once a second guard needs it.
Nothing misbehaves today; the cost comes the first time one copy learns a new spelling, such as an escape it should skip, and the other does not.

Next step: add a merge to `lib/bouncer_parse.py` that returns `(body, span, is_funsub)` in source order, have both guards call it, and `make sync`.
