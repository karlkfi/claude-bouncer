# Claim Q-IDs on the remote instead of hand-picking them

Three namespaces merged into one store and nothing reserves an ID, so two sessions filing rows can both pick the next number. `session-backlog` ships `alloc-queue-id.sh`, which claims `refs/queue-ids/QN` on origin as a compare-and-swap, and `queue.py claims`, which fails an ID a branch adds without one. Measured 2026-08-22: `git ls-remote origin 'refs/queue-ids/*'` returns nothing, so wiring the gate needs every migrated ID excused with `--allow` or backfilled — the migration commit adds all of them.
