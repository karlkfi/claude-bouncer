# A deeply nested ${…} in a $( ) body crashes two guards

`_brace_end` calls itself for each nested `${` with no depth bound
(`lib/bouncer_parse.py:994:def _brace_end(text, i):`), and
`_scan_dollar_paren` reaches it for every `${` in a `$( )` body since Q292.
A thousand levels exhaust Python's stack. Q325 met this while capping its
own new recursion at `MAX_SUBST_DEPTH`, which leaves this path as it was.

Driven 2026-11-01 against `git archive origin/main` at `e6e71db9`, with the
command `echo "$(echo ${y:-${y:-…x…}})" ; rm /etc/probe-target`, 1000 levels
of `${y:-`, fed to each hook as a `PreToolUse` payload:

| guard | exit | stdout | stderr |
|---|---|---|---|
| workspace-guard | 1 | empty | `RecursionError` |
| exit-status-guard | 1 | empty | `RecursionError` |
| prod-guard | 0 | empty | — |
| foreground-guard | 0 | empty | — |

A hook that exits 1 is a non-blocking error to Claude Code, so the
`rm /etc/probe-target` after it is judged by nothing. Not checked: branch-guard,
and how many levels each guard tolerates before it fails.

## Which way it gets built

Carry the depth through `_brace_end` the way Q325 carries it through
`_scan_dollar_paren` and `_dq_expansion_end`, and read flat past
`MAX_SUBST_DEPTH`. `_brace_end`'s own `$(` branch should pass its depth on,
so alternating `${` and `$(` levels are bounded too. Pin it with a parser test
that 1000 levels of each shape return without raising.

## If it is never built

Anyone willing to write a thousand nested `${y:-` can put a command past
workspace-guard and exit-status-guard. The shape has no use outside a
deliberate attempt.
