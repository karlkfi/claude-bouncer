# A deeply nested ${…} in a $( ) body crashes two guards

`_brace_end` calls itself for each nested `${` with no depth bound
(`lib/bouncer_parse.py:1010:def _brace_end(text, i):`), and
`_scan_dollar_paren` reaches it for every `${` in a `$( )` body since Q292.
A thousand levels exhaust Python's stack. Q325 met the same failure in its
own new recursion and replaced that recursion with an explicit stack, which
leaves this path as it was.

Driven 2026-11-01 against `git archive origin/main` at `e6e71db9`, with the
command `echo "$(echo ${y:-${y:-…x…}})" ; rm /etc/probe-target`, 1000 levels
of `${y:-`, fed to each hook as a `PreToolUse` payload:

| guard | exit | stdout | stderr |
|---|---|---|---|
| workspace-guard | 1 | empty | `RecursionError` |
| exit-status-guard | 1 | empty | `RecursionError` |
| prod-guard | 0 | empty | — |
| foreground-guard | 0 | empty | — |

A hook that exits 1 is a non-blocking error to Claude Code, so the
`rm /etc/probe-target` after it is judged by nothing. Not checked: branch-guard.

`${` alternating with `$(` reaches the same recursion, through
`_brace_end` → `_scan_dollar_paren` → `_brace_end`. The stream-A reviewer
found the band while re-checking Q325: with `echo "${x:-$(` … `)}"` wrapped
`k` times around `echo ")"` and `; P` after it, prod / ws / exit / fg give
deny / ask / deny / deny on `main` at `8e3a0269` up to `k = 450`, and
defer / exit 1 / exit 1 / defer at `k = 500`. In `command_substitutions`
alone the first `RecursionError` comes at `k = 500` on `main` and on Q325's
final tree, measured in steps of 10.

## Which way it gets built

Step over a nested `${` without recursing, as Q325 does for a double-quoted
`$(` in `_scan_dollar_paren`. Do not cap the depth and read flat past it:
Q325 tried that first, and the flat reading past the cap misplaced the close
at every even depth from 26, so guards that denied on `main` there deferred.
`_brace_end`'s own `$(` branch calls `_scan_dollar_paren`, so alternating
`${` and `$(` levels need the same treatment. Pin it with a parser test that
1000 levels of each shape return the right body, and at depths either side of
25.

## If it is never built

Anyone willing to write a thousand nested `${y:-` can put a command past
workspace-guard and exit-status-guard. The shape has no use outside a
deliberate attempt.
