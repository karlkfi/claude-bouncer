# A bundled sudo or env flag hides a watch from foreground-guard

`strip_head` drops a `sudo` or `env` option by testing the whole token against
a value-flag set, so it recognises a value-taking flag only when the flag is
written on its own. In a bundle the token matches nothing, one word is dropped
instead of two, and the flag's value is left standing as the command word.

Measured 2026-10-01 at `b27be8d` by driving the hook with a JSON payload:

| command | guard |
|---|---|
| `sudo -u root gh run watch 456` | deny -- control |
| `sudo -n gh run watch 456` | deny -- control |
| `sudo -nu root gh run watch 456` | **defer** |
| `sudo -bu root gh run watch 456` | **defer** |
| `env -u FOO gh run watch 456` | deny -- control |
| `env -i gh run watch 456` | deny -- control |
| `env -iu FOO gh run watch 456` | **defer** |
| `env -iC / gh run watch 456` | **defer** |

`env -iu FOO` and `env -iC /` run the command after them. That was driven for
prod-guard's twin, Q200, with a payload absent from `PATH` under
`env -i bash --norc --noprofile -c`. For sudo the evidence is its usage line,
which puts `-n` and `-b` among the bundleable flags and `-u` among those that
take a value.

## Which way it gets built

Decide arity per character, stopping at the first value-taking flag: the rest
of the token is that flag's value, and when the flag ends the token, the next
word is. Q200's fix builds that in prod-guard as one helper over every
wrapper's option loop. It is not shared, and the flag sets differ, so it is a model for
this fix rather than a call site.

Q160 is the other half of this guard's arity problem: `exec`, `time` and
`stdbuf` have no value-flag set at all. Its fix gives them sets. Whichever row
lands second should route its loop through the same per-character walk, so
the guard keeps one arity rule.

`timeout` is left out on purpose. A timeout-wrapped segment defers by design,
so a mis-peeled `timeout -vk 5 10` changes nothing here.

## If it is never built

A watch written behind an ordinary bundled sudo or env flag parks the main
thread with no deny. The cost is waiting, not an outage.
