# A brace group, conditional or loop hides a git command from branch-guard

branch-guard never strips a leading shell reserved word, so `{`, `if`,
`then`, `!` and `do` become the segment's program. None of them is `git`, so
the segment is non-git and the command defers with no prompt. `{ …; } 2>&1` is
the commonest of these shapes in agent-written commands, and it carries a
force push to `main` past the guard.

## Measured

2026-10-07, branch-guard at `main` `63ceb4d`, hook driven with its cwd on a
checkout of `main`, by the orchestrator and again in this session against
`5a5552d`:

| command | verdict |
|---|---|
| `git push --force origin main` (control) | ask |
| `( git push --force origin main )` (control) | ask |
| `{ git push --force origin main; }` and `… } 2>&1` | **none** |
| `if true; then git push --force origin main; fi` | **none** |
| `! git push --force origin main` | **none** |
| `while true; do …; break; done`, `for i in 1; do …; done` | **none** |
| `f() { git push --force origin main; }; f` | **none** |

`git commit -m x` gives the same table. workspace-guard, exit-status-guard
and foreground-guard catch all nine, per the orchestrator; prod-guard has the
same miss as Q300.

## Mechanism

`command_segments` hands each segment straight to `parse_invocation`, which
reads the first word after any assignments as the program. The shared
`strip_sh_keywords` is the step the working guards run first.

The fix has a second half, because branch-guard also follows a `cd` to decide
which branch a later segment acts on. `(` and `)` were plain separators, so a
`cd` inside a subshell leaked out: from `main`, `( cd ../feat ); git commit`
was judged on the feature branch and got no decision. Stripping `{` alone
would add the mirror case, a `cd` inside `if false; then …; fi` followed as
though it ran.

## Which way it gets built

Strip with the shared `strip_sh_keywords` in `command_segments`, keeping
`time` for the wrapper walk, and hand the stripped words and the parens to a
scope tracker: a `cd` persists out of `{ }`, is undone by `)`, and leaves the
cwd unknown after a body that may not run.

## If it is never built

A force push or a commit to `main` written inside a group, a conditional or a
loop reaches the branch with no prompt.
